\# TaskFlow — Smart Study Planner



TaskFlow is a responsive task management application designed to help students organize their study sessions, prioritize tasks, and track their progress.



\## Live Demo



https://saronelly123-ui.github.io/week4-todo-app/



\## GitHub Repository



https://github.com/saronelly123-ui/week4-todo-app



\## Features



\- Add tasks with input validation.

\- Assign Low, Medium, or High priority to tasks.

\- Mark tasks as completed or active.

\- Edit task names.

\- Delete tasks with confirmation.

\- Filter tasks by All, Active, and Completed.

\- Search tasks by name.

\- Display total tasks and remaining tasks.

\- Show a progress bar for completed tasks.

\- Clear completed tasks.

\- Save tasks in localStorage so they remain after refreshing the page.

\- Switch between light and dark themes.

\- Responsive layout for different screen sizes.

\## Getting Started



\### Prerequisites



Install Node.js and npm.



\### Installation



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/saronelly123-ui/week4-todo-app.git

&#x20;  ```



2\. Open the project folder:



&#x20;  ```bash

&#x20;  cd week4-todo-app

&#x20;  ```



3\. Install dependencies:



&#x20;  ```bash

&#x20;  npm install

&#x20;  ```



4\. Start the development server:



&#x20;  ```bash

&#x20;  npm run dev

&#x20;  ```



5\. Open the local URL shown in your terminal.



\## Production Build



To build the application for production, run:



```bash

npm run build

```



Vite generates the production files in the `dist` directory.



\## Deployment


Live demo: https://saronelly123-ui.github.io/week4-todo-app/
The application is deployed to GitHub Pages. GitHub Actions builds the Vite application and deploys the generated `dist` directory when changes are pushed to the `main` branch.



\## Usage



1\. Enter a task name.

2\. Choose a priority.

3\. Click \*\*Add task\*\*.

4\. Mark tasks as completed when finished.

5\. Use search and filters to find tasks.

6\. Edit or delete tasks when needed.

7\. Use the theme toggle to switch between light and dark mode.



\## Accessibility and Responsive Design



TaskFlow uses semantic HTML, form labels, accessible button names, and visible focus styles. The layout adapts to different screen sizes.
