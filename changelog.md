# Changelog

This file records notable updates to the TaskFlow Smart Study Planner project.

## Initial Release

- Created the TaskFlow todo application using Vite and JavaScript.
- Added task creation, editing, completion, and deletion.
- Added task search and All, Active, and Completed filters.
- Added light and dark theme support.
- Added persistent task storage.
- Configured Tailwind CSS for styling.
- Configured GitHub Pages deployment using GitHub Actions.
- Added project setup instructions in `README.md`.
- Added a manual testing guide in `testing.md`.
- Added a production build check using `npm run check`.
