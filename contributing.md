# Contributing to TaskFlow

Thank you for your interest in improving TaskFlow — Smart Study Planner.

## Getting Started

1. Clone or download the repository.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.

## Making Changes

1. Make a focused change to the application or documentation.
2. Test the affected functionality in the browser.
3. Run `npm run check` to verify the production build.
4. Review your changes before committing.

## Commit Messages

Use clear commit messages that explain the purpose of each change.

Examples:

- `feat: improve task management`
- `fix: correct a task filtering issue`
- `docs: update project instructions`

## Pull Requests

When contributing through a pull request, describe the change, explain how it was tested, and mention any known limitations.

## Project Standards

- Keep changes focused and easy to review.
- Avoid committing generated files or dependencies.
- Update documentation when behavior or setup instructions change.
